# Quizdeck vision

Quizdeck helps people study their own multiple-choice question sets through
accessible web and terminal interfaces, without being tied to a subject, course,
or certification.

It supports learning with explanatory feedback and focused practice with clear
progress reporting. Study progress stays local and persistent so people can pause
and return without losing their work.

Both interfaces aim to offer the same core study experience, with keyboard-friendly
navigation and clear control over question content and progress.
